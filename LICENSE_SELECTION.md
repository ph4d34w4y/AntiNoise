# License selection before publishing

This package intentionally does **not** choose a license on behalf of the project team.

If the team wants AntiNoise to be open source, choose a license before publishing. Two common choices:

- **MIT** — short and permissive.
- **Apache License 2.0** — permissive and includes an explicit patent grant.

After the team agrees, add the standard license text as a root-level file named `LICENSE` and update the README License section.

Do not label the repository “open source” until a license has been selected.
